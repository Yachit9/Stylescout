# Stylescout Fashion helper
This app uses firecrawl for web Scraping, the websites are manually mentioned and firecrawl's search tool is not used. After the scraping it is fed into openai's gpt-oss-20b model which is considered good for reasoning using Groq and for backend Fastapi has been used. Only one Fetch call has been made in frontend javascript where it collects the final data after being proessed by the LLM. LLM has been strictly instructed to give the reccomendation based on the data provided after scraping and not invent anything from itself.
